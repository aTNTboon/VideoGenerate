🎬 VideoGenerate
自动化视频生成 Demo —— 输入脚本，一键输出带配音、字幕和画面的 MP4 视频

VideoGenerate 是一个轻量级的自动化视频生成工具，基于 Edge-TTS 免费语音合成 + FFmpeg 音视频处理 + Pillow 画面渲染。无需昂贵的视频编辑软件，只需一段文字脚本，即可自动生成可用于抖音、B站、小红书等平台的短视频。

核心亮点：纯 Python 实现、零成本、支持批量生成、代码即视频。

✨ 功能特性
🗣️ 智能配音 —— 基于 Edge-TTS 调用微软神经语音，免费、无需 API Key、音质自然

🎨 自动画面生成 —— 根据场景描述自动生成渐变背景图或信息图风格画面

📝 同步字幕 —— 自动生成 SRT 字幕文件并叠加到视频中

🎬 一键合成 —— FFmpeg 自动合并图片、音频、字幕，输出标准 MP4

📦 批量生产 —— 支持多脚本批量处理，适合内容矩阵运营

🎵 背景音乐 —— 支持添加 BGM，音量智能调节

🛠️ 技术栈
组件	技术	说明
语音合成	Edge-TTS	微软 Edge 在线 TTS，免费无限制
图像渲染	Pillow	Python 绘图库，生成场景画面
音视频合成	FFmpeg	音视频编解码核心引擎
字幕生成	自动生成 SRT	与音频同步的逐句字幕
核心语言	Python 3.8+	全流程 Python 驱动
